# Harris Teeter Clip All

Adds a "Clip all" button to the bottom right of the
[e-VIC coupons page](https://www.harristeeter.com/savings/cl/coupons/). It loads
every coupon, then clicks each "Clip" button about once a second. Press it again
to stop.

## Install in Firefox

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on** and pick `manifest.json` from this folder.

Temporary add-ons are removed when Firefox restarts.

Sign in to Harris Teeter before pressing the button.
